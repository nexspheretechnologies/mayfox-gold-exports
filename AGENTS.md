# Project notes

- `npm run dev` serves on port 8080. Production build is `npm run build` (Vite + Nitro,
  `node-server` preset) and runs with `npm start` from `.output/server/index.mjs`.
- `vite.config.ts` assembles the TanStack Start plugin set directly. Route tree
  (`src/routeTree.gen.ts`) is generated by the build; do not hand-edit it.
- Server-only code lives under any `**/server/**` path or imports `server-only`;
  the build fails on client import of either.
- Required environment variables are listed in `.env.example`. Never commit `.env`.
- Leads and inquiries are stored in Supabase; schema changes go in `supabase/migrations`.
- Keep the branch in a working state: deploys build from the pushed branch.
